SANT KABIR VIDYAPEETH P.G. COLLEGE WEBSITE

Files:
- index.html: website structure and content
- style.css: responsive design and styling
- script.js: mobile menu, image slider and enquiry email form
- images/: the three college photos supplied for this website

HOW TO VIEW:
1. Extract the ZIP file.
2. Open the sant_kabir_college_website folder.
3. Double-click index.html to open it in Chrome.

HOW TO PUBLISH ON GITHUB:
1. Create a GitHub repository.
2. Upload index.html, style.css, script.js and the complete images folder.
3. Open repository Settings > Pages.
4. Under Build and deployment, select Deploy from a branch.
5. Choose main branch and /(root), then Save.

IMPORTANT:
- The enquiry form opens the visitor's default email app. It does not save submissions to a database.
- Course cards are starter content. Confirm the current approved courses, eligibility, fees, phone number and other official details with the college before publishing.
- Replace the phone number if the college wants a different public contact number.
